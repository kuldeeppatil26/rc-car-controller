If set, only devices advertising this name prefix appear in the pairing list. Leave blank to filter by Service UUID instead (recommended).
Off by default so the pairing list shows every nearby BLE device — some may appear as "Unknown or Unsupported Devices," pick yours by elimination. Turn this on once you've confirmed the car connects, to hide unrelated devices.
Can't tell which one is your car? Open the Arduino Serial Monitor after uploading — it prints the exact MAC address to match against the "(xx:xx:xx…)" shown in each list entry. Seeing "Unknown or Unsupported Device" itself is normal for a custom board like this; it just means Android doesn't recognize the profile type.
Defaults match the Nordic UART Service UUIDs used in the companion ESP32 sketch — only change these if you've customized the firmware.
